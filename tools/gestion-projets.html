Gérer mes projets

Préparez vos fiches et leurs images dans votre copie locale du portfolio. Rien n’est envoyé ni publié automatiquement.

Un navigateur compatible est nécessaire

L’accès au dossier local nécessite l’API File System Access, disponible dans les versions récentes de Chrome et Edge. Ouvrez cet outil dans l’un de ces navigateurs, puis choisissez le dossier racine du dépôt.

Si l’outil est ouvert directement depuis un fichier et que le navigateur bloque l’accès, servez localement le dépôt avec un serveur HTTP local, puis ouvrez cette page sur votre ordinateur. Aucun service distant n’est nécessaire.

1. Choisir le dossier du portfolio

Sélectionnez le dossier qui contient _projets, _data et index.html. L’outil demandera l’autorisation d’y lire et d’y écrire.
